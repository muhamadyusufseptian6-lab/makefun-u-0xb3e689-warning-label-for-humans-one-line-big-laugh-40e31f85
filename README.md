Satu baris label peringatan keamanan yang seharusnya tercetak di setiap manusia — lucu dulu, masuk akal kedua. Dibangun untuk bounty make.fun **Warning Label for Humans: One Line, Big Laugh** ($5, lima hadiah @ $1).

## Cara kerja

`main.ts` (Node 22, stdlib-only, deterministik) menulis satu baris teks ke `$MAKEFUN_OUTPUT_DIR/entry.txt`. Tidak ada dependensi, tidak ada network, tidak ada input dari luar.

## Jalankan

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
